О нашем проекте

Наша миссия

Мы стремимся предоставить пользователям удобный доступ к актуальным новостям из различных источников, используя современные технологии и персонализированные рекомендации.

Основные возможности

  • Агрегация новостей из различных источников
  • Персонализированные рекомендации на основе интересов
  • Удобная система фильтрации и поиска
  • Возможность сохранения избранных статей
  • Telegram-бот для удобного доступа к новостям

Технологии

Наш проект разработан с использованием современных технологий:

  • Python и Django для бэкенда
  • PostgreSQL для хранения данных
  • Машинное обучение для рекомендаций
  • Адаптивный дизайн для всех устройств
